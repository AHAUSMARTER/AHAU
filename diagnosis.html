核心概念混淆 · 洛必达求导未定式前置检验缺失

概念性漏洞 (Core Misconception)
原题背景与考点研读：本题考查微分学核心考点：0/0 型未定式极限求解。原式在 x 趋于 0 时，分子 sin(0) - 0 = 0，分母 0³ = 0，属于标准 0/0 未定式。常规解法有两条路径：一是连续应用洛必达法则求导，二是应用泰勒（麦克劳林）公式展开。由于分母为 x³，分子进行泰勒展开能够一步消去低阶无穷小，是最不易发生算术失误的最优路径。
规范分步求解推导：
1. 验证未定式型态：\(\lim_{x \to 0}(\sin x - x) = 0\)，\(\lim_{x \to 0} x^3 = 0\)，为 \(\frac{0}{0}\) 型未定式；
2. 麦克劳林级数展开：回忆基本展开式 \(\sin x = x - \frac{x^3}{3!} + o(x^3) = x - \frac{x^3}{6} + o(x^3)\)；
3. 分子代换化简：分子 \(= (x - \frac{x^3}{6} + o(x^3)) - x = -\frac{x^3}{6} + o(x^3)\)；
4. 计算极限：\(\lim_{x \to 0} \frac{-\frac{1}{6}x^3 + o(x^3)}{x^3} = -\frac{1}{6} + \lim_{x \to 0}\frac{o(x^3)}{x^3} = -\frac{1}{6}\)。
标准答案 / 严谨结论： \(-\frac{1}{6}\)
解题思路精要：分母为 \(x^3\) 时，优先利用麦克劳林展开至 3 阶，一招消去低阶无穷小，规避洛必达连续 3 次求导失误风险。

常见误解与正确判断
常见误解
看到分式形式立即求导，未检验极限是否趋于 0/0，存在“将任意除法极限当成导数比值”的机械套公式心智习惯。
正确判断
洛必达法则源自柯西中值定理，必须满足未定式型态与导数商极限存在。非未定式时直接使用将导致结果完全失真。
随堂自测
【探针自测题】在计算极限时，若分子极限为 0 但分母极限非 0，若直接使用洛必达法则上下求导，会发生什么？
