# 高德校园地图代理

公开前端：`campus_map.html`，GitHub Pages 部署；代理：
`https://anau-campus-map-proxy.jaderook8.chatgpt.site`。

当前 Sites 项目 ID：`appgprj_6b0483a490288191a7787ffe53da93ea`。
独立代理托管工作区是本机 `map_proxy/`（独立 Git 仓库，不作为主仓库子模块提交）。
本目录保存无密钥的代理源码，修改后同步至该工作区并重新发布。
迁移到其他 Cloudflare Worker 时，`worker.mjs` 可作为 Worker ES module 入口。

## 服务端环境变量

- `AMAP_JS_KEY`：高德 Web端（JS API）Key，通过 `/config` 提供给浏览器 SDK；此标识在浏览器请求中可见。
- `AMAP_SECURITY_CODE`：安全密钥，仅存在服务端；不传给浏览器，不提交 Git。

原始本机配置在项目目录外，不能复制进源码或构建产物。
在高德控制台为 JS API Key 设置实际使用域名白名单；第三方托管的可用性及账号配额应由维护者持续检查。

## 接口与访问边界

- `GET /health`：仅报告是否配置，不返回凭据。
- `GET /config`：返回浏览器 SDK 的公开标识和代理地址。
- `GET /_AMapService/...`：仅代理源码白名单内的高德只读接口；替换 Key 并追加安全密钥；固定 HTTPS 上游，不跟随重定向。
- CORS / Referer 限制来源为项目 GitHub Pages、本地演示端口、代理自身。来源检查并非身份认证；每 IP / isolate 每分钟 90 请求限制是演示级限流，不是分布式全局用量保障。
- 脚本回调接口按 JavaScript MIME 返回，配合 `nosniff`。
- 地点搜索与路线起终点会发送给高德；本代理不持久化搜索、位置或路线。托管平台仍可能保留平台请求日志。
